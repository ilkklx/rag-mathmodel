# 评测

## 一、评测集

| 项 | 值 |
|----|-----|
| 名称 | 数学建模 RAG 问题集 v2（Ground Truth，人工逐条核对） |
| 题数 | **50**（聚合 10 + 普通 40；五类各 10：建模方法 / 算法 / 公式与数学关系 / 相似赛题 / 综合） |
| 文件 | `data/ground_truth/eval_set_v2.json` |
| 判相关规则 | 命中 `primary_sources` / `secondary_sources`，或正文含 ≥`min_hits` 个 `relevant_knowledge` 关键词 |
| 内容标签 | `data/ground_truth/content_labels_v2.jsonl`（DIRECT / PARTIAL / UNCERTAIN） |
| 冻结对照 | `data/ground_truth/baseline_v2_snapshot.json`（50 题 × Top-10 的 path/chunk_id/text_hash） |

## 二、三种口径（必须分开陈述）

| 口径 | 定义 | 说明 |
|------|------|------|
| **legacy Hit@K** | 文件级：Top-K 中是否存在"相关"文件 | 宽松，只看文件 |
| **内容级 DirectHit@K / MRR@10** | 逐题找出第一个被标注为 **DIRECT**（真正直接回答问题）的位置 | 严格，人工标注 |
| **槽位 / 去重双分母** | Phase 6 聚合专用（此处不适用） | 防止"槽位当文档"的混用 |

> 只报 legacy 会显著高估效果——本包实测 legacy Hit@10 = 0.90，而内容级 DirectHit@10 = 0.40。

## 三、本包实测结果

由 `python scripts/eval_gt50.py` 现场重跑产出，结果文件：`manifests/eval_gt50_result.json`。

复算内容标签时用 `text_hash = sha1("".join(text.split()))[:16]`（与原项目一致）。

| 指标 | 本包重跑值 | 冻结基线值 | 是否一致 |
|------|-----------|-----------|:--------:|
| Top-10 与冻结快照逐条一致 | **50/50** | — | ✅ |
| DirectHit@5 | **0.34** | 0.34 | ✅ |
| DirectHit@10 | **0.40** | 0.40 | ✅ |
| MRR@10 | **0.2509** | 0.2509 | ✅ |
| legacy Hit@5（重算） | **0.90** | 0.90 | ✅ |
| legacy Hit@10（重算） | **0.90** | 0.90 | ✅ |

> **说明**：50 题 Top-10 逐条一致 ⇒ 所有下游指标必然一致。上表同时给出"重算值"与"冻结值"，用于交叉证明移植是等价的。

## 四、性能（实测）

|----|-----|
| 50 题总耗时 | 2.72 s |
| 平均每问 | 0.054 s |
| 最大单问 | 2.14 s（首次调用含模型加载） |
| 单次冒烟检索 | 约 0.28 s（模型已加载） |

## 五、已知偏差

- **内容标签覆盖率 486/500**：有 14 个 Top-10 条目在原标签集中没有对应标签，按"非 DIRECT"处理（与原口径一致）；
- 本包的检索与冻结基线同源，未做任何参数调整；**若你改了 `rrf_k` / `pool` / `topk`，上表数字不再成立**。
